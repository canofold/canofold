# 指南

指南按建站流程组织。第一次使用请从[入门](/guide/introduction/)开始；需要查询字段、命令或 API 时进入[参考](/reference/)。

- [入门](/guide/introduction/)：安装 Docfuse 并创建第一个站点。
- [内容创作](/guide/writing/)：组织 Markdown、静态资源和 MDX 组件。
- [站点能力](/guide/site/)：配置导航、搜索、多语言、版本、主题和插件。
- [发布与运营](/guide/delivery/)：检查、构建、部署和维护站点。
