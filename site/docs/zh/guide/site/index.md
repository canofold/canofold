# 站点能力

- [导航与路由](/guide/site/navigation/)：URL、顶部导航、递归侧栏和页面顺序。
- [搜索](/guide/site/search/)：内置 compact 搜索与可选 Pagefind 插件。
- [多语言](/guide/site/internationalization/)：Locale 目录、界面文案和翻译缺口。
- [文档版本](/guide/site/versions/)：独立内容快照与版本切换。
- [重定向](/guide/site/redirects/)：迁移公开 URL 并阻止循环或链式跳转。
- [主题定制](/guide/site/customization/)：基础配色、Logo 和语义 Token 覆盖。
- [构建扩展](/guide/site/extensions/)：在站点构建过程中转换源码、补充页面信息或生成项目文件。
- [官方插件](/guide/site/plugins/)：为 Markdown 启用数学、图表、链接处理和阅读时长，或把搜索切换到 Pagefind。
