# 安装

Docfuse 需要 Node.js 22 或更高版本。建议安装为项目开发依赖，让本地开发和 CI 使用锁文件中的同一版本。

:::code-group[包管理器]

```bash title="pnpm"
pnpm add -D docfuse
```

```bash title="npm"
npm install --save-dev docfuse
```

```bash title="yarn"
yarn add --dev docfuse
```

:::

安装完成后，继续[快速开始](/guide/introduction/getting-started/)创建配置和文档目录。
