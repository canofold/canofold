# 产物与质量

本组记录静态构建的输出契约，以及上线前需要检查的质量和安全边界。

- [构建产物](/reference/output/build-artifacts/)：HTML、Markdown 镜像、资源、搜索、SEO 和重定向文件。
- [AI 友好输出](/reference/output/ai-output/)：`llms.txt`、Manifest、分片语料和页面索引。
- [故障排查](/reference/output/troubleshooting/)：根据症状查找配置、内容、搜索或部署问题。
- [安全边界](/reference/output/security/)：内容信任、外部服务、私有访问和 CSP。
