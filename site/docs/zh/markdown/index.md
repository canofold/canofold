# Markdown SDK

`@canofold/markdown` 是可独立使用的 Markdown SDK。它提供 React 渲染、构建与 SSR、内容分析、主题契约和浏览器增强，Canofold CLI 也用它生成文档页面。

它支持代码、表格、提示块、Tabs、Steps、文件树、媒体等文档元素；数学和图表通过官方插件启用。

- [使用 Markdown 包](/markdown/usage/)：安装并接入 React、SSR 或静态 HTML。
- [Markdown 语法参考](/markdown/syntax/)：查询标准语法、Canofold 指令和属性约束。
- [Playground](/markdown/playground/)：在源码与渲染结果之间对照查看支持的元素。
- [React Markdown API](/reference/api/react-markdown/)：查询 Props、类型和公共入口。

站点导航、搜索、多语言、版本和部署属于 Canofold CLI，请查看[指南](/guide/)。
