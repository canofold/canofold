# Guide

The guide follows the site-building workflow. Start with [Introduction](/en/guide/introduction/) if you are new to Canofold. Use the [Reference](/en/reference/) to look up fields, commands, and APIs.

- [Introduction](/en/guide/introduction/): evaluate Canofold and create a first site.
- [Writing](/en/guide/writing/): organize Markdown, static assets, and MDX components.
- [Site capabilities](/en/guide/site/): configure navigation, search, locales, versions, themes, and plugins.
- [Delivery and operations](/en/guide/delivery/): check, build, deploy, and maintain the site.
