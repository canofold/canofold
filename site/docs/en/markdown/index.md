# Markdown SDK

`@docfuse/markdown` is a standalone Markdown SDK. It provides React rendering, build and SSR support, content analysis, theme contracts, and browser enhancement. The Docfuse CLI uses it to render documentation pages as well.

It supports code, tables, callouts, tabs, steps, file trees, media, and other documentation elements. Math and diagrams are enabled through official plugins.

- [Use the Markdown package](/en/markdown/usage/): install it for React, SSR, or static HTML.
- [Markdown syntax reference](/en/markdown/syntax/): look up standard syntax, Docfuse directives, and attribute constraints.
- [Playground](/en/markdown/playground/): compare supported source syntax with rendered output.
- [React Markdown API](/en/reference/api/react-markdown/): look up props, types, and public entries.

Navigation, search, locales, versions, and deployment belong to the Docfuse CLI. See the [Guide](/en/guide/).
