# Support

Use GitHub Discussions for usage questions and design proposals, and GitHub Issues for reproducible bugs or scoped feature requests. Search existing discussions and issues first.

A useful bug report includes the Canofold and Node.js versions, operating system, package manager, sanitized configuration, smallest reproduction, expected behavior, actual output, and the relevant command log. Do not attach secrets or private documentation.

Security vulnerabilities must follow [SECURITY.md](./SECURITY.md) and must not be opened as public issues. The latest release line is the supported line; older `0.x` minors may require upgrading before a fix can be applied.
